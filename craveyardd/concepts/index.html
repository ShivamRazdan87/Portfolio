CraveYardd concepts

Five design directions for the CraveYardd website. Each one uses the same menu, prices and photos, so you can compare the look and feel side by side. Open them on your phone for the best impression.

01

Chocolate Drip

Built with GSAP and ScrollTrigger. A dark, cinematic, scroll-driven story: the cup photo opens from a circle, you ride sideways through the cups, chocolate lines draw under the waffles and toppings fall like sprinkles.

Ready to view 02

Candy Pop

Built from 21st.dev components (shadcn Button, Magic UI Marquee) and the same open-source libraries 21st.dev distributes: animated headline, rotating product names, shimmer buttons, a glowing border, tilt cards, a bento grid and a spotlight card. Motion comes from the components, no GSAP.

Ready to view 03

Scroll Sundae

GSAP drives the scroll: a stack of cups fans out, the menu rides sideways on desktop, chocolate colour fills the About text. 21st.dev components supply the marquee, shimmer buttons, photo slider, spotlight and magnetic button.

Ready to view 04

Sweet Blocks

Guided by UI UX Pro Max: a hero-led layout built to convert, with bold colour blocks and soft clay cards. Live open/closed status, a menu with tabs, a sticky action bar for thumbs and its GSAP stagger preset.

Ready to view 05

Ultimate Craving

Everything together: UI UX Pro Max sets the structure (a hero built to convert, clay blocks, live opening status, sticky thumb bar, a map). 21st.dev components supply the interface and GSAP drives the scroll motion with UI UX Pro Max’s stagger preset.
